# E-commerce Relationship Risk GNN

这是一个使用受控离线数据研究电商账号关系风险的图学习原型。项目把账号、设备、IP、地址和订单组织成异构关系图，比较表格模型与多种图神经网络，并通过独立校准和低基率最终留出集评价模型。

系统输出账号风险概率、关系证据和候选关联组件，供人工复核使用。它不自动封禁账号，不修改业务订单，也不宣称已经达到生产部署要求。

## 数据与结论边界

- 数据为受控离线生成数据，不包含真实用户身份或真实业务记录。
- 标签与模型输入物理隔离，并按实体划分训练、验证、校准和测试数据。
- 最终结果用于研究比较和人工复核辅助，不代表生产环境效果。
- 公开材料不包含本地路径、内部服务配置、账号明细或访问凭据。
